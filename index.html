        选择 / 导航

        方向键 空间导航（选最近的节点）

        Tab / Shift+Tab 顺序轮转

        [ ] 在左右画布间切换

        Enter 打开详情并聚焦标题框

        Esc 取消选中 / 退出连线



        编辑

        N 新建节点（建在当前画布选中节点右侧）

        E 改标题

        D / Del 删除节点及其连线

        Shift+方向 移动 10px　Alt+方向 移动 1px 微调



        连线

        L 或 C 进入连线模式 → 方向键选目标 →
        Enter 确认 → 输入类型

        类型简写：improves replaces combines
        quires fails_when uses

        replaces 必须写替代条件，否则会被拒。

        鼠标方式：Shift + 从节点拖到另一节点。



        视图 / 面板

        + - 缩放　0 复位　滚轮也可缩放

        1 详情　2 AI 辅助　3/? 本页

        / 搜索　Ctrl+Enter 全图检查

        Ctrl+Z 撤销　Ctrl+Y 重做　Ctrl+S 导出 JSON



        鼠标（可选）

        拖节点=移动 · 拖空白=平移 · 双击节点=改名 · 双击空白=新建



        两图关系

        右图节点在详情里填「关联左图技术」（如 T03, T05）。
        右图出现蓝点、左图对应节点被引用时也显示蓝点。



        自动检查

        左图节点缺失效条件 → 红虚线框（等于宣称它不会坏）

        边是 replaces 但没写条件 → 边变红

        右图节点没关联技术 / 没说明 → 详情里报

        点顶部「检查」看全图问题清单，点条目可直接跳过去。
